## 1. 심심함의 원인과 수정 방향
- 선택지가 "착한 답 = 수치 상승"이라 정답 고르기가 됐다 → 정중한 선택끼리도 **얻는 정보·함께하는 장면·맡는 역할**이 달라지게 바꿈
- 일기가 미션 보상 창에 머물렀다 → **"원래 미래의 기록 → 개입 → 문장 변화"** 페이지 4개로 실제 사건과 연결
- 인물이 반응만 했다 → 하늘(교환학생 고민)·서린(역할 부여)·서윤(인터뷰 제안)이 **먼저 연락하고 제안**
- 첫 15~20분에 궁금한 미래가 없었다 → 프롤로그에서 **"7주 토요일, 2학기 첫날 하늘이 자리는 비어 있었다"** 제시 (실제 플레이 시간은 측정 전)

## 2. 새 설정
- 🆕 정하늘: **일본 교환학생(2학기부터 1년) 지원을 고민 중.** 7주 토요일의 "할 얘기"는 고백이 아니라 이 고민 (감정 자각은 기존대로 12주)
- 🆕 한서윤: **학보사 기자.** 꿈은 사람들 인터뷰를 모은 사진집 출간. 조용하지만 물러서지 않는 성격
- 🆕 강서린: E06에서 비밀을 지키면 **부스 동선안을 맡기고 7주 회의 발표를 지시** (공개 인정 ≠ 연애 유지)
